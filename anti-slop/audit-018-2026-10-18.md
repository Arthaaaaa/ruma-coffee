# Anti Slop Audit 018 - 2026-10-18

Scope: the sales bar chart on the Ruma Coffee admin overview.

## Findings

1. **LOW - R-26: Hover did not reveal the selected date and value in the chart.** Bars only changed color and exposed their data through the browser's native `title` tooltip.
2. **LOW - R-03: Dense date ranges could exceed the plot width on phones.** A 2px minimum bar width plus a 3px gap for as many as 90 bars can demand more width than the chart has.

## Requested resolution

The user asked for the reference chart's spring-like staggered bars, useful hover feedback, and a mobile layout that stays inside its card. Keep the existing Ruma Coffee palette and use the current chart data and date filters.
