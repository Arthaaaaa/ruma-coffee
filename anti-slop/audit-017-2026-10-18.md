# Anti Slop Audit 017 - 2026-10-18

Scope: the custom date range picker in the Ruma Coffee admin dashboard.

## Finding

1. **LOW - R-19: The custom range still relies on two native date fields.** The selected period is split across separate controls, so users cannot scan or adjust a range in the requested two-month calendar view.

## Requested resolution

The user explicitly requested a single range button with a two-month calendar popover. Keep the existing 90-day sample-data bounds and apply the selected dates to the dashboard filters.
